# Workflow FAQ

**Modèle :** un membre **rédige** une FAQ complète (il maîtrise le sujet).  
Ce n’est pas une simple demande « pourriez-vous faire une FAQ ? ».

## Formulaire membre

| Champ | Rôle |
|-------|------|
| **Sujet** | Titre de la question / thème |
| **Rédiger la FAQ** | Réponse précise et cohérente (texte publié tel quel) |

Parcours : **Rédiger une FAQ** → Envoyer pour revue → suivi dans **Mes FAQ**.

## Actions admin

| Action | Effet |
|--------|--------|
| Demander un complément | Retour auteur avec note |
| Refuser | Rejet (resoumission possible) |
| **Publier la FAQ** | Approuve + publie en une étape |

FAQ publiée = sujet dans le forum **FAQ**, **lecture seule** (pas de réponses membres).

## États (libellés FR + badges)

| Code | Affiché | Couleur |
|------|---------|---------|
| `pending` | En attente | Orange |
| `under_review` | En revue | Bleu |
| `changes_requested` | Modifications demandées | Ambre |
| `approved` | Approuvée | Vert clair |
| `published` | Publiée | Vert |
| `rejected` | Refusée | Rouge |

**Refus ≠ suppression.** Une FAQ refusée reste en base ; l’auteur peut **corriger et renvoyer**.  
Suppression manuelle uniquement via **Retirer** (en attente / complément demandé).

Le libellé du forum reste **FAQ** ; sa description suit le thème communauté (`/admin/setup`).
